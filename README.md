# 비상대피로 도면 편집기 (Evacuation Route Map Editor)

공장·사업장의 **비상대피로 안내도**를 브라우저에서 직접 그려 PNG/PDF로 뽑는 단일 파일 웹앱입니다.
외부 라이브러리 없이 `index.html` 하나로 동작합니다.

## 기능
- 바닥 도면 이미지 불러오기(배경)
- 벽 그리기
- 대피 경로(초록 화살표) 그리기
- 안전 심볼 배치: 비상구 · 소화기 · 소화전 · 발신기 · 완강기 · 구급함 · 대피장소 · 현위치
- 글자 라벨, 되돌리기, 전체 초기화
- 제목란(사업장명 · 층 · 작성일) 자동 표기
- PNG 저장 · 인쇄/PDF · 프로젝트 저장(JSON)/불러오기

## 사용
`index.html`을 브라우저로 열면 됩니다. (설치·서버 불필요)
